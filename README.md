# Gestión Fábrica

Sistema de gestión para plantas de tejido circular y sin costura. **Versión de demostración**.

Todo corre en el navegador con una planta de ejemplo de 20 máquinas: no hay servidor,
no se guarda nada y al recargar la demostración vuelve a empezar.

## Módulos

| Módulo | Para qué sirve |
|---|---|
| Panel | Punto de entrada, explica el flujo completo |
| Producción diaria | App de los operarios: abrir y cerrar lotes, paros, entrega de turno |
| Tablero maestro | Supervisión en vivo: eficiencia, tubos, paros por equipo |
| Planta virtual | Plano de la planta con el estado de cada máquina y el personal en movimiento |
| Hojas de vida de máquinas | Historial técnico: mantenimientos, cambios de elementos, fotos |
| Personal | Hojas de vida, turnos, novedades y cotejo de timbradas con horas extras |
| Fichas técnicas | Composición de hilo, peso y tiempo estándar por referencia |
| Materia prima | Pedido de hilo según lo que está corriendo |
| Planeación | Gantt proyectado por máquina |
| Desarrollo de producto | Seguimiento de referencias nuevas por etapa |

En una instalación real los datos viven en la nube y se sincronizan entre los celulares
de planta, el tablero de supervisión y la oficina.

La clave del módulo de personal en esta demostración es **1234**.
